02Experience23.5050° N · 41.2300° E

Senior GIS Developer, ESNAD (Saudi Mining Services Company)Jul 2025 – Present · Riyadh

Digital mining licenses for the Ministry of Industry and Mineral Resources

Spatial auto-deduction, run in your browser

  1. 1Applied boundary received
  2. 2Overlap check against existing licenses
  3. 3Geometry adjusted to business rules

The polygons are synthetic, not real licenses. The overlap and the adjusted shape are computed with the ArcGIS geometry engine (intersect, difference, geodesic area) and extruded on the terrain. The production engine does this server-side behind a REST API.

  • Designed the GIS solution and data-flow architecture for digital mining license issuance: license boundaries, mining sites, and approval workflows.
  • Built a custom GIS portal with the ArcGIS Maps SDK for JavaScript (MapViews, layers, geometry creation and editing), plus apps in Experience Builder and ArcGIS Dashboards.
  • Built the spatial auto deduction engine as a REST API that adjusts license geometries against business rules and existing boundaries.
  • Integrated the platform with other government systems over REST for licensing approvals, and exposed spatial endpoints for other departments to consume.
  • Built print templates and geoprocessing automation with Python and ArcPy, and a search that turns plain-language questions into SQL over GIS data.
  • Use Claude Code, Codex, and GitHub Copilot for coding, refactoring, and reviews, with MCP connectors into internal tools and data.
